# Ward Office Appointment System

*A self-initiated systems analysis and delivery case study by Basant Tamang.*

Citizens visiting ward offices in Kathmandu often queue without knowing how long they will wait or which documents to bring, and many need a second visit. Staff cannot plan their day because demand is unpredictable. This project analyses that service and specifies, prototypes and tests an online appointment system for it.

## Approach

1. Interview citizens and ward staff about recent visits
2. Map the current process and its pain points
3. Write requirements that trace back to those pain points
4. Design the data model and API
5. Build a prototype with a small volunteer team and run user acceptance testing
6. Manage delivery with a baselined plan, weekly status reports and change control
